# Запуск динамічної частини (Top-Selling / Bouquets)

Дані підвантажуються через `axios` з локального `json-server`, що читає `db.json`.

## 1. Запустити json-server

Не потрібно нічого встановлювати глобально — можна одразу через `npx`:

```bash
npx json-server --watch db.json --port 3000
```

(або `npm install -g json-server`, а потім `json-server --watch db.json --port 3000`)

Переконайтесь, що сервер піднявся на `http://localhost:3000` і що
`http://localhost:3000/bouquets` віддає масив букетів.

## 2. Відкрити index.html

Відкрийте `index.html` (бажано через Live Server / будь-який локальний http-сервер,
щоб уникнути CORS-обмежень `file://`).

## Як влаштована логіка (js/app.js)

- **Top-Selling Bouquets** — запит `GET /bouquets?category=top`. Отримані 6 букетів
  рендеряться динамічно (`insertAdjacentHTML`) у `.bestsellers-list`, а самі точки
  пагінації (`.pagination-dots`) теж генеруються з даних. Стрілки `prev`/`next` і клік
  по крапці зсувають "вікно" з 3 карток по колу (CSS сам ховає 2-у/3-ю картку на
  мобільних/планшетних брейкпоінтах — верстка не змінювалась).
- **Bouquets** — запит `GET /bouquets?_page=N&_limit=4` (json-server пагінація).
  Кнопка **Show More** довантажує наступну сторінку без перезавантаження сторінки.
  Коли сервер повертає менше елементів, ніж `_limit` (тобто колекція закінчилась),
  кнопка ховається і зʼявляється повідомлення "You have viewed all our bouquets.".
- Обидва запити обгорнуті в `try/catch` — при помилці (наприклад, json-server не
  запущено) користувач бачить зрозуміле повідомлення замість порожнього блоку.
